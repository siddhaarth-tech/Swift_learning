Public type not equal to public members
            
public struct Car {
    var speed = 100   // internal
}
Need:
public var speed = 100

if you want speed to be public.

}

Nested types

public struct Car {
    private struct Engine {
    }
}

Possible.
A nested type can be more restricted than the outer type.

Tuple
Access level = most restricted part.
(internal, private) -> private

Function
Function cannot expose something more restricted than itself.
public function
      
private return type
      
no

Enum
Enum cases automatically have the same access as the enum.
public enum Direction {
    case north   // public
    case south   // public
}

Superclass -> internal
Subclass   -> public (no)

Subclass cannot be more accessible than its superclass.

Protocol
Public protocol -> its requirements must be implemented as public.

Extension

Extensions can add methods/properties to a type.
extension Car {
    func drive() {}
}

Members are usually internal by default for public/internal types.
